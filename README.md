# Z280-RCBus

Z280 MPU modules in RCBus standard with microcontroller for clock distribution, initialisation of the ‘Bus Timing and Initialization Register’ :

- stand-alone, with its own 512kB memory, operating in bootstrap mode only;
- universal, enabling traditional boot from ROM or via serial bootstrap.

The Z280's default clock is 9.216MHz for internal and external bus operations.
